## 第 5 步：装到 iPhone

**在 Windows 电脑上装**，需要三样东西：

### 5.1 先装驱动

Sideloadly 需要苹果的驱动才能识别 iPhone：

- 去 https://www.apple.com/itunes/download/win64 下载 **iTunes**（别用微软商店版）
- 装好 iTunes 就行，不用打开它

> 如果 Sideloadly 后面提示"找不到设备"，八成是这步没做好。

### 5.2 装 Sideloadly

下载：https://sideloadly.io

装好后打开。

### 5.3 安装 ipa

1. 用数据线把 iPhone 连到电脑
2. iPhone 上弹「要信任此电脑吗」→ 点**信任**
3. Sideloadly 界面：
   - `iDevice` 选你的 iPhone
   - 把 `MsgBridge.ipa` 拖进 `IPA` 框
   - `Apple ID` 填你的 **Apple ID 邮箱**（就是登录 App Store 那个）
4. 点 **`Start`**
5. 弹出框要求输入 Apple ID 密码

> ⚠️ **如果你的 Apple ID 开了双重认证**（大概率开了）：
> 普通密码用不了。要去 https://appleid.apple.com →
> 「登录与安全」→「App 专用密码」→ 生成一个，
> 把这个 16 位的密码填进 Sideloadly。

6. 等进度条走完，手机上就出现 App 了

## 第 6 步：在 iPhone 上信任

第一次打开会提示「不受信任的开发者」：

1. iPhone：**设置 → 通用 → VPN与设备管理**
2. 找到你的 Apple ID 那一行
3. 点进去 → **信任**
4. 回到桌面，App 就能打开了

## 用起来

1. **电脑端**：双击 `start.bat`，记下窗口里显示的「手机端地址」，形如 `http://192.168.1.10:8765`
2. **手机**：连上**同一个 Wi-Fi**，打开 App → 「同步」页 → 填入那个地址
3. 点「立即同步」，消息就进来了

之后每次电脑端收到新的工作消息，手机上点一下同步就能看到。

## 常见问题

**Q：App 装好了，但同步拉不到数据**
- 手机和电脑必须连**同一个 Wi-Fi**（手机别用流量）
- 电脑上的 `start.bat` 必须**开着**
- 地址要带端口，形如 `192.168.1.10:8765`，别漏了
- Windows 防火墙可能拦了。第一次跑 `start.bat` 时如果弹窗问是否允许，要点**允许**

**Q：7 天后 App 打不开了**
免费 Apple ID 签的 App 只有 **7 天**有效期。
到期后重新走一遍第 5 步（ipa 不用重新编译，直接用之前下载的那个）。
想省事就买 99 美元/年的开发者账号，能签 1 年。

**Q：能上架 App Store 吗？**
不能。上架版不能有"抓取其他 App 通知"这类功能，审核会拒。
自用就好。

**Q：消息存在哪？**
只存在你手机本地（App 自己的沙盒里），不上传任何服务器。
电脑端也存一份在 `messages.json`。
